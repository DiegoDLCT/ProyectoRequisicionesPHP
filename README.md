# Sistema de Gestión de Requisiciones y Compras

## 📋 Descripción
Sistema web desarrollado en PHP para la gestión digital de requisiciones y compras empresariales.

## 🚀 Características
- ✅ Autenticación segura con roles
- ✅ Formularios inteligentes por área
- ✅ Gestión de requisiciones y cotizaciones
- ✅ Sistema de aprobaciones
- ✅ Interfaz responsive y profesional

## 🛠️ Tecnologías
- **Backend:** PHP nativo, MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Arquitectura:** MVC personalizado
- **Seguridad:** Password hashing, Sessions

## 📁 Estructura del Proyecto
ProyectoPHP/
├── backend/ # Lógica de negocio
├── frontend/ # Interfaz de usuario
├── uploads/ # Archivos subidos
└── database/ # Scripts de BD


## 👥 Roles del Sistema
- **Administrador:** Acceso completo
- **Jefe de Área:** Crear y ver sus requisiciones
- **Jefe Mayor:** Aprobar cotizaciones

## 🔧 Instalación
1. Clonar repositorio
2. Configurar base de datos MySQL
3. Importar estructura de tablas
4. Configurar conexión en `backend/config/database.php`
